# 界面内帮助资源

`zh-CN/` 提供发行包内 14 份帮助的简体中文版本，英文原文继续保留在 `public/helps/`，原有英文资源 URL 不变。这里只翻译界面内帮助，不翻译开发文档。

已有 `scripts/i18n/prepare.js` 在构建准备阶段将两种语言的 Markdown 复制为带内容哈希的静态资源，并将地址写入 `resource-index.json`。地图帮助组件通过该索引加载当前语言；资源地址使用部署的 `ROOT_PATH`，不会使用项目名称或地图 URL 参数拼接路径。

帮助弹窗沿用 Showdown 和 DOMPurify。切换语言或关闭弹窗时取消旧请求；旧请求的结果不能覆盖新语言。语言变化后立即隐藏旧正文并显示加载状态。资源不存在、HTTP 请求失败或正文为空时显示当前语言的错误与重试按钮，不静默显示另一种语言。

中文正文保留技术字段、代码示例、接口路径、URL、公式和数值。图层筛选帮助将 `NOT AND` 明确表述为逻辑与后取反；视线分析帮助的默认地形范围说明与已有 `shadowReach` 扩展选项保持一致，避免原英文开头与后文相互矛盾。参数表的 `shadowReach` 单位按实际后端实现修正为千米（后端乘以 1000 转为米），原英文表中的米为文档错误；英文原文仍保留。

本任务依赖 T2 的共享资源生成和 T3 的地图语言实例。开发后只运行 review skill，必要集成验证由父任务统一在 60 隔离副本中通过 QA skill 执行；未新增或执行自定义测试。
