## 工具：视线分析

_计算并展示地形对轨道目标或天体目标的视线可见性。_

**说明：**默认计算观察者与目标的方向关系以及当前屏幕范围内的地形。屏幕外未加载的远处山体不会产生阴影；如需考虑屏幕外地形，可设置下方的“阴影外延范围”。

### 界面

每个视线分析项都是独立的分析地图，具有各自的源对象、观察者、显示设置和计算模式。可以同时创建多个分析项，并通过左侧的不同颜色边框区分。

- _时间_
  - 工具顶部的共享时间区域显示**开始时间**、**结束时间**和**步长（分钟）**。开始和结束时间可以直接编辑，使用 ISO 8601 格式的 UTC 时间，例如 `2023-09-06T00:00:00Z`。不带时区的 `YYYY-MM-DDThh:mm:ss` 也可输入，并按 UTC 处理。修改后移开焦点或按 Enter，会校验输入并更新全局时间扫描范围及 MMGIS 时间轴。无效输入会恢复为最近一次有效值。步长指定相邻计算时刻之间的分钟数，用于合成和回放扫描。这些字段与 MMGIS 时间轴联动；点击屏幕左下角的时钟图标可展开时间轴。可以在此处或时间轴中设置扫描时间。

#### 分析项顶部栏

每个分析项的顶部栏包含：

- _复选框_：开启或关闭分析地图图层。
- _名称_：可编辑的分析项名称。
- _源对象下拉列表_（170 像素）：选择用于计算遮挡的源对象，包括航天器、轨道器或天体。
- _拖动柄_：拖动以调整分析项顺序。
- _关闭（X）_：删除分析项。

#### 源对象

- _观察者_
  - 选择用于观察的航天器或轨道器。此设置通过 chronice API 格式化和转换时间参数。实际观察位置始终是可见地图中心的经纬度，由绿色圆圈标识，默认朝北且倾斜角为零。
- _高度_
  - 计算视线遮挡时使用的距地表高度，单位为米，对可见地形中的所有点生效。逐步增大此值，可查看距地表不同高度处的视线分析结果。
- _DEM_
  - 选择此分析项使用的地形数据集，参见下方的 **DEM 数据集配置**。即使只配置一个 DEM，也会显示此列表。所选 DEM 同时用于视线地图和地平线剖面计算。DEM 配置包含 `resolution` 时，列表下方会显示数据集的原生分辨率，单位为米/像素。
- _分辨率_
  - 相对比例为 1×、0.5×、0.25×（默认）或 0.125×，与视口最长边的像素数相乘，决定输出网格尺寸，最小为 50 像素。比例越小，计算越快，结果越粗。选择器下方显示实际工作地面分辨率，单位为米/像素，约等于视口地面范围除以输出网格尺寸。该数值随地图移动和缩放更新，便于了解当前设置的实际细节程度。配置 DEM 原生 `resolution` 后，输出网格及实际分辨率不会细于原生分辨率，避免超出数据精度的过采样。
- _阴影外延范围_
  - 将用于阴影计算的地形加载范围延伸至可见地图区域之外，单位为千米。此范围内的地形以较低分辨率读取，使远处的山脊、陨石坑边缘等地形可以在视口内投下阴影，同时减少对完整分辨率计算速度的影响。设置为 0 时，仅使用视口范围。
- _自定义方位角／仰角／距离_
  - 用手动输入的值覆盖 SPICE 计算的方位角、仰角和距离。

#### 显示

- _颜色_：在地图上标识可见区域的颜色。
- _不透明度_：分析图层的不透明度，0 表示透明，1 表示不透明。

#### 运行

**运行**区域包含模式选择器和生成控件。点击“运行”标题可展开或收起下方结果；模式选项卡和生成或扫描按钮始终显示。

- _模式选项卡_（静态／合成／回放）
  - 选择此分析项的可见性计算与显示方式。切换模式会清除地图中已渲染的结果图层。
- _生成／扫描按钮_
  - **静态模式**：“生成”计算单个时刻的分析地图。设置变化时自动生成。
  - **合成或回放模式**：“扫描”根据开始时间、结束时间和步长，对全部时刻进行时间范围分析。每次扫描最多 4096 帧。
  - **取消扫描**：扫描过程中，按钮持续显示进度，右侧上方会出现一个小“×”。点击“×”，通过 `AbortController` 终止当前请求；后端逐帧流式处理检测到连接关闭后，会结束计算。

##### 静态模式结果

生成按钮下方显示紧凑的方位角和仰角指示器：

- _方位角指示器_：俯视图显示源对象的方位，并标注数值，例如“方位角：123.4°”。
- _仰角指示器_：侧视图显示源对象的仰角，并标注数值，例如“仰角：45.6°”。

##### 合成模式结果

显示累计可见性热力图，每个像素的颜色表示其在全部计算时刻中的可见频率。

- _色带选择器_：选择热力图使用的颜色渐变。
- _连续／离散_：选择平滑插值色带，或使用分档颜色。
- _绝对范围／适应数据_：“绝对范围”使用 0% 至 100% 的可见性范围；“适应数据”根据实际最小、最大可见性值调整色带，以提高视觉对比度。
- _图例_：显示颜色渐变及两端的数值。在 Leaflet 地图上将鼠标移到分析结果上，图例会标示对应像素的可见性值。
- _可拖动色标_（离散模式）：分档边界上会显示小拖动柄，拖动可调整各档的相对宽度。点击重置图标（↻）可恢复均匀间隔。

##### 回放模式结果

逐帧播放各计算时刻的结果。只有构建帧图集后才会显示回放指示器：可直接在回放模式扫描，也可在合成模式完成扫描后切换到回放模式，按需构建帧图集。

- _天空穹顶图_：使用极坐标图显示源对象在扫描时间段内的天空轨迹，并高亮当前位置。
- _小型方位角／仰角指示器_：位于天空穹顶图容器的顶部角落，显示当前帧中源对象的方向。
- _播放／暂停／逐帧按钮_：控制动画。向前或向后逐帧操作每次移动一帧。
- _时间轴滑块_：跳转到扫描中的任意一帧，并显示当前帧的时间戳。
- _联动／独立切换_：位于播放控件右侧的链条图标。
  - **联动**（默认，突出显示）：所有联动分析地图同步播放；在任意卡片上点击播放，其他联动卡片同时前进。
  - **独立**（暗色显示）：使用独立时间轴；拖动或逐帧操作仅影响当前分析地图。

#### 导出

存在可导出的数据时，此区域出现在结果部分，依次显示“导出”、格式下拉列表和下载图标。

- _视线分析地图（PNG）_：将当前分析地图导出为 PNG 图片，全部瓦片画布合成为一张图片。
- _扫描结果（CSV）_：将时间范围扫描结果导出为 CSV 文件，列为 `time`、`lat`、`lng`、`visibility_pct`、`azimuth`、`elevation`、`range`。`lat`／`lng` 列为观察者（源点）坐标。完成扫描后才可使用。
- _视线分析网格（TXT）_：将二维可见性网格导出为纯文本文件，包含源对象、观察者、时间、扫描范围、网格尺寸和值图例等元数据头。合成或回放模式的值为可见性比例（0.0–1.0）；静态模式使用整数代码：0 表示被遮挡，1 表示太阳可见，2 表示地球可见，8 表示无 DEM 数据，9 表示超出范围。

导出文件名包含当前设置的上下文，例如 `sightline_SUN_MSL-HAZCAM_2024-01-01T000000Z_sweep.csv`。

### 算法

#### 视线地图（视域）

**接口：**`POST /api/sightline/sightmap`

计算二维可见性网格，判断哪些地形单元与源对象具有直接视线。

**核心算法：**

1. **源对象位置**：SPICE 根据指定时间，计算观察者（地图中心经纬度和高度）到目标的方位角、仰角和距离。自定义源对象直接使用用户输入的方位角和仰角。
2. **DEM 合成**：读取配置的地形栅格，并在视口四周扩展 `shadowReach` 范围，捕获屏幕外地形产生的阴影。工作尺寸不超过最大尺寸的 4 倍，以防止内存耗尽。
3. **切平面投影**：将观察者位置和源对象向量投影到局部切平面。在与网格对齐的坐标系中，源对象的有效位置表示为 (x, y, z)。
4. **射线步进视域计算**：从每个网格单元沿源对象方位发出射线。算法采用 Jianjun Wang、Gary J. Robinson、Kevin White 所著 [_Generating Viewsheds without Using Sightlines_](https://www.asprs.org/wp-content/uploads/pers/2000journal/january/2000_jan_87-90.pdf) 的修改版本，记录向外步进时遇到的**最大地形仰角**。每个采样点通过周围四个 DEM 单元进行**双线性插值**，遇到无数据时回退到最近邻；减去曲率修正 `d² / (2R)`，再将仰角 `atan2(terrain_h − cell_h, distance)` 与源对象仰角比较。累计最大角度达到源对象仰角时，该单元**被遮挡**；完成步进仍未达到时，该单元**可见**。采样间距参见下方“自适应步进”。
5. **输出**：二维整数网格，`0` 表示被遮挡，`1` 表示目标可见，`2` 表示辅助源对象（地球）也可见，`8` 表示无 DEM 数据，`9` 表示超出范围。

**参数：**

| 参数 | 类型 | 默认值 | 说明 |
|-----------|------|---------|-------------|
| `dem` | string | — | 所选 DEM 栅格路径，位于 `/Missions/` 下，由每个分析项的 DEM 选择器确定 |
| `lat`, `lng` | number | — | 观察者纬度和经度 |
| `height` | number | 0 | 观察者距地形的高度，单位为米 |
| `target` | string | — | SPICE 目标名称，例如 `SUN`、`MRO` |
| `time` | string | — | ISO 8601 格式的 UTC 时间，用于单时刻模式 |
| `startTime`, `endTime`, `stepSeconds` | string/number | — | 批量时间扫描参数 |
| `obsRefFrame` | string | `IAU_MOON` | SPICE 观察者参考坐标系 |
| `obsBody` | string | `MOON` | SPICE 观察者天体名称 |
| `planetRadius` | number | 0 | 行星半径，单位为米，用于曲率修正 |
| `maxOutputDim` | number | 400 | 最大网格尺寸，上限为 4096 |
| `shadowReach` | number | 0 | 屏幕外阴影计算额外加载的 DEM 范围，单位为米 |
| `isCustom` | string | `'false'` | 为 `'true'` 时，使用 `customAz`／`customEl`，不使用 SPICE |
| `customAz`, `customEl` | number | 0 | 自定义源对象方位角和仰角，单位为度 |

**自适应步进：**

逐像素采样每条射线，对大型网格而言速度过慢。因此，步长会随距离以及源对象高于已知地形的角度差增大。相比逐像素步进，可获得约 **7–14 倍加速**。平滑地形不会漏过遮挡物；尖锐且狭窄的地形，如仅数像素宽的山脊顶或陨石坑边缘，可能被跨过，下方的步长上限用于限制此问题。

- **渐进 log₂ 步进**：基础步长为 `march_step × max(1, log₂(r + 1))` 像素，`r` 是当前像素距离。观察者附近逐像素采样，因为此处每步的角度变化最大；远处步长增大，例如 r = 1000 时约为 10 倍，r = 25000 时约为 15 倍。
- **角度余量加速**：当源对象仰角明显高于累计最大地形角时，进一步增大步长：余量大于 5° 时乘以 3，大于 2° 时乘以 1.5。较大余量表示附近地形距离遮挡源对象尚远，可以更粗地采样。
- **步长上限**：组合步长限制为 `march_step × 6`，防止加速机制直接跳过远处狭窄的遮挡物。这使动画帧之间的阴影边缘平滑移动，减少突变。降低上限可减少漏过的遮挡物，但会降低速度。
- **提前截断**：步进受 `MAX_TERRAIN_H / tan(source_el)` 限制，超出此距离的地形无法达到源对象；还受曲率上限 `√(2 × R × MAX_TERRAIN_H)` 限制，超出后曲率下降量大于可能的地形高度。步进期间，如果当前距离上最高可能地形也无法超过累计最大角度，则停止。

**性能：**

- **分辨率管理**：合成 DEM 的工作尺寸限制在最大尺寸的 4 倍，防止较大阴影外延范围导致内存耗尽。
- **曲率限制**：阴影外延范围上限为 `√(2 × planetRadius × 10km)`。
- **批量流式处理**：DEM 和 SPICE 内核仅加载一次，每帧只重新计算源对象向量，并逐帧报告进度。
- **帧数限制**：每次扫描的最大帧数与分辨率反向变化，每帧单元越少，允许帧数越多：256 帧（`maxDim ≥ 800`）、512 帧（`≥ 400`）、1024 帧（`≥ 200`）、4096 帧（更细的档位，例如 0.125×）。超出限制时，需要增大时间步长。

#### 地平线剖面

**接口：**`POST /api/sightline/horizonprofile`

计算观察者在各个方位看到的地形天际线。

**核心算法：**

对每个方位角进行以下操作，默认以 1° 间隔计算 360 个方向：

1. **初始化射线**：从 DEM 中的观察者像素向外发出射线，方向计算考虑非正方形像素。
2. **采样地形**：每一步通过 DEM 网格双线性插值得到地形高程。
3. **曲率修正**：提供行星半径时，从采样高程中减去 `d² / (2R)`，其中 `d` 是水平距离，`R` 是行星半径。
4. **仰角**：`el = atan2(terrain_elev - observer_elev, horizontal_distance)`。
5. **记录最大值**：将沿射线遇到的最大仰角记录为该方位的地平线，同时记录此点的距离。
6. **输出**：每个方位对应 `[azimuth_deg, max_elevation_angle_deg, distance_meters]` 数组。

**参数：**

| 参数 | 类型 | 默认值 | 说明 |
|-----------|------|---------|-------------|
| `path` | string | — | DEM 栅格路径，位于 `/Missions/` 下 |
| `lat`, `lng` | number | — | 观察者纬度和经度 |
| `observerHeight` | number | 0 | 观察者距地形的高度，单位为米 |
| `numAzimuths` | number | 360 | 方位数量，上限为 3600 |
| `maxRadius` | number | 5000 | 射线步进的最大距离，单位为米，上限为 500 千米 |
| `minSkipRadius` | number | 0 | 跳过此距离内的地形，单位为米 |
| `planetRadius` | number | 0 | 行星半径，单位为米，用于曲率修正；0 表示平面 |

**性能：**

- **对数步进**：步长为 `step = max(1, log₂(r + 1))` 像素。观察者附近每步 1 像素，距离 1000 像素时约为 10 像素。在近处保持精度，远处跳过重复采样。250 千米范围内，每条射线的采样数约从 2500 减少至 600。
- **提前结束**：超过 1 千米后，每次采样都会检查：当前距离上最高可能地形（10 千米起伏，扣除曲率下降）能否超过当前最大角度。不能时立即停止。大多数射线在 50–200 次采样后结束。
- **综合加速**：相比逐像素步进，每条射线的采样数减少约 4–8 倍。

#### 可见性时间轴

**接口：**`POST /api/sightline/visibility`

为回放中的**可见性时间轴**提供数据，即地平线剖面图下方各源对象的可见或遮挡状态条。每个采样时刻从观察者向各源对象发出一条**原生分辨率射线**，比较源对象仰角与该方向的地形地平线，不从扫描网格中读取像素。因此，结果不依赖地图缩放或工作分辨率。

- **可见性采样倍率**：图表面板顶部、地平线多边形复选框右侧的 `1x…256x` 下拉列表，默认 `16x`，指定每个扫描时间步计算多少个样本。`1x` 表示每步一条射线；较高倍率在扫描帧之间增加插值样本，使时间轴更平滑。请求的 `stepSeconds` 为 `sweepStep ÷ samplingRate`。如果较长时间范围与高倍率的组合超过后端样本上限 32768，会自动增大步长，使结果保持在上限内，避免请求失败。
- **算法**：沿用地平线剖面的对数步进和提前结束机制，但每个样本只沿源对象方位发出一条射线，不扫描全部 360°。每个样本输出 `{time, az, el, horizonAngle, visible}`。
- **说明**：合成热力图的可见百分比序列仍使用扫描网格；只有时间轴逐帧的可见或遮挡状态使用此专用射线。

### 配置

- `dem`（string，旧版）：单个 DEM 路径，为兼容旧配置保留，仅在 `dems` 列表为空时使用。
- `dems`（array）：可供选择的 DEM 列表，每项包含：
  - `name`：显示在各分析项 DEM 下拉列表中的名称。
  - `path`：相对于项目目录的云优化 GeoTIFF（COG）DEM 路径。
  - `resolution`（可选）：DEM 的原生地面采样间距，单位为米/像素，由项目管理员填写。配置后，会在下拉列表下方显示原生分辨率，并限制实际工作分辨率，避免超出数据精度的过采样。未配置时，不显示原生分辨率，也不据此限制实际分辨率。

此配置方式与 `MeasureTool` 的 `layerDems` 一致。`dems` 为空或未配置时，仍使用旧版单个 `dem` 字段，原有单 DEM 配置继续生效。
