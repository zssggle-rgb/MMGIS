# MMGIS 中文界面验收计划

生成：plan-eng-review，2026-10-13；仓库 zssggle-rgb/MMGIS；当前分支 zh-CN；推荐实施基线正式 tag 5.2.24。
状态：待实施，当前新增计划组通过数 0/18。不得连接现有数据库做破坏性测试。

## 页面与关键流程

地图 `/`：二维、三维、影像、全部 11 个内置工具、独立弹窗、提示和帮助。
后台 `/configure`：任务、图层、数据集、工具、权限和服务配置；保存、导入导出与读回。
认证：发行包所有登录、注册与密码页面；按实际路由清单逐项检查，不猜测 URL。
实际部署在子路径时，以上路径带 ROOT_PATH；同时检查 EXTERNAL_ROOT 代理场景。

每组至少包含正常、边界、失败场景；中文用 zh-CN 上下文，英文用 en 上下文。所有条目都是发布前要求，未标记为已测试。

| 编号 | 检查与预期 |
|---|---|
| R1 语言规则 | 无设置默认中文；合法 URL lang 优先于 cookie；无效语言安全回退。禁用 cookie/localStorage 后仍可使用，不白屏。 |
| R2 字典清单 | 所有可见文本/ARIA/提示/动态键均可定位；中英文键及参数匹配，漏键或占位符错阻断构建/中文测试；业务数据不被计作软件文案。 |
| R3 启动 | 两套前端、传统页面、服务端都及时得到对应资源；缺资源构建失败，不能先显示大片英文或出现未定义键。 |
| R4 同步 | 主界面、独立 React 弹窗、多个标签页切换一致；反复切换无事件回环；关闭弹窗后无残留订阅。 |
| R5 状态 | 后台有未保存文本、地图有未完成绘图时切换，内容/焦点/视角保留；传统 tooltip 和工具内部动态文字更新。 |
| R6 元数据控件 | 普通下拉、可搜索下拉、嵌套对象数组、动态数据选择器的标签中文；保存值、类型和对象结构与英文相同。 |
| R7 错误反馈 | HTTP、WebSocket、本地校验的成功/失败均中文；未知 key/缺参数/第三方原始英文错误有中文概要和技术详情。旧 status/message/业务字段保持兼容，仅允许白名单增量字段。 |
| R8 安全显示 | 中文带参数、引号、尖括号正确显示；恶意 HTML/脚本作为文本或经清洗，不执行；认证错误与格式化描述同样检查。 |
| R9 路径与刷新 | 子路径、代理路径、刷新、跨地图/后台、cookie path 有效；切换保留任务名、视角及无关 URL 参数。 |
| R10 帮助 | 14 份界面内帮助切换正确；慢响应不覆盖新语言；404 显示中文失败及重试；原英文帮助 URL 保持有效。 |
| R11 认证 | 所有认证视图、弱密码/错密码/权限不足/会话过期均中文；并发中英文请求不串语言；功能仍可登录与退出。 |
| R12 后台数据 | 配置创建/编辑/保存/读回/导入/导出；对业务配置结构和值进行比对，不能将中文标签写入技术键或枚举。 |
| R13 地图工具 | Draw、Measure、Viewshed、Identifier、Sites、Layers、Animation、Curtain、Info、Legend、Sightline 及二维/三维/影像交互全部检查。外部依赖不可用也有中文说明；英文行为同样通过。 |
| R14 嵌入控件 | 上传、日期选择、JSON 编辑器及嵌入 API 交互外壳的按钮/提示为中文；代码、接口路径和独立技术文档正文不翻译。 |
| R15 无遗漏 | 打开隐藏菜单、弹窗、空状态、错误与动态控件；中文审计钩子发现缺键即失败，不能仅按截图首页估计覆盖率。 |
| R16 中文排版 | 1280、800、390 宽度与既有响应式范围；中文字体可用，无遮挡、截断或无法点击。术语统一；长文本、缩放和键盘焦点可用。 |
| R17 交付资源 | 干净环境安装两套依赖、构建、镜像拉取启动；资源索引与最终 manifest 一致，帮助/传统脚本/Pug 都存在；两种语言均运行。 |
| R18 升级恢复 | 受限备份恢复到全新独立卷；英文基线迁移及旧镜像恢复登录/配置/附件读回成功。切换暂停写入；开放写入后回滚保留新数据增量。 |

## 关键发布门槛

- 新增公共函数具有行为、边界与错误测试；新增模块行覆盖率至少 80%，关键分支完整。
- 保留现有英文测试并实际运行，两种语言选择器、工具身份和原始数据值一致。
- 同环境比较启动和切换：新增压缩资源建议每前端 ≤150 KiB，首次可用增量同时 ≤10% 和 ≤150 ms，切换 P95 <100 ms；目标待测。
- 报告记录测试源码版本、镜像 digest、测试环境、结果和失败，不将源码审查当作运行通过。
- 自动测试、翻译人工校核、部署副本恢复与实际界面验收分别记录。
